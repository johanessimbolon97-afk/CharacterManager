Character Manager — TP3 (Java Visual SIH-6406)
Deskripsi
Character Manager adalah program berbasis Java untuk mengelola data karakter dalam sebuah game. Program ini menerapkan konsep Object-Oriented Programming (OOP), termasuk encapsulation, constructor, dan enum untuk mengatur tipe karakter. Program juga menyediakan method isAlive() untuk memeriksa apakah karakter masih hidup berdasarkan jumlah HP yang dimiliki.
